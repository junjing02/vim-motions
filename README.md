# Terminal IDE Cheatsheet

Stop context-switching to look up shortcuts. One page for **Neovim**, **tmux**, **lazygit**, **Claude Code**, and the **Corne 42** split keyboard — search it, browse it, works on your phone too.

- A **Workflow** tab showing how all five actually fit together in one real coding session, not five disconnected cheatsheets
- Shortcuts organized by category, with instant search across the current tool
- Curated plugin/resource picks for each tool, with a one-line reason to care
- A Corne 42 tab covering layers, QMK/ZMK keycodes, home row mods — plus upload your own `.vil` keymap export to see your actual layout rendered
- Optional "Practice Motions" drill mode to build Neovim muscle memory

## Run locally

```
npm start
```

Then open `http://localhost:8000`.
