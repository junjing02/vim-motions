# Terminal IDE Cheatsheet

Stop context-switching to look up shortcuts. One page for **Neovim**, **tmux**, **lazygit**, and the **Corne 42** split keyboard — search it, browse it, works on your phone too.

- Shortcuts organized by category, with instant search across the current tool
- Curated plugin picks for each tool, with a one-line reason to install
- A Corne 42 tab covering layers, QMK/ZMK keycodes, home row mods, and layout resources for beginners
- Optional "Practice Motions" drill mode to build Neovim muscle memory

## Run locally

```
npm start
```

Then open `http://localhost:8000`.
